# Camera Violation Detection System
## 📋 Обзор системы
### Комплексная система компьютерного зрения для детекции нарушений в видеопотоках. Система объединяет несколько типов детекторов для мониторинга качества видео и безопасности в режиме реального времени.

#### 🚀 Основные возможности
*1. Детекция перекрытий камеры*

- CV-детектор: анализ яркости, контраста, резкости изображения

- Детектор темных областей: обнаружение крупных затемненных зон

- YOLO-детектор: идентификация объектов, перекрывающих кадр

*2. Детекция движения камеры*

- ORB-детектор: анализ угловых и линейных смещений

- Фильтрация ложных срабатываний: подтверждение движений по времени и кадрам

- Интеллектуальная запись: автоматическое сохранение сегментов с движением

*3. DMS (Driver Monitoring System)*

- Детекция состояния водителя: открытые/закрытые глаза

- Контроль ремня безопасности: периодическая проверка

- Обнаружение запрещенных действий: использование телефона, курение

- Кулдауны нарушений: предотвращение спама уведомлений

*4. Детекция запрещенных предметов*

- YOLO-детекция: еда, напитки, электронные устройства

- Перклассовые кулдауны: раздельные таймеры для разных типов объектов

- Трекинг объектов: отслеживание предметов во времени

##### Детекторы и их параметры

**CVDetector (анализ качества изображения)**
```
brightness_thresh=25      # Порог яркости (0-255)
contrast_thresh=10        # Порог контраста
sharpness_thresh=20       # Порог резкости (Laplacian variance)
```

**DarkAreaDetector (темные области)**
```
dark_area_threshold=0.8   # Порог темных пикселей (0-1)
```

**YOLODetector (объекты)**
```
area_threshold=0.7        # Минимальная площадь объекта (0-1)
conf_threshold=0.5        # Уверенность детекции
```

**CameraMovementDetector**
```
rotation_threshold=8.0    # Порог поворота (градусы)
translation_threshold=0.12 # Порог смещения
min_matches=20           # Минимальное совпадение точек
min_movement_duration=2.0 # Минимальная длительность движения
confirmation_frames=8    # Кадры для подтверждения
```

**ForbiddenItemsDetector**
```
min_detection_duration=3.0  # Минимальное время детекции
violation_cooldown=30.0     # Кулдаун между нарушениями
class_specific_cooldown=True # Отдельные кулдауны для классов
```

**DMSDetector**
```
eye_closed_threshold=5.0    # Время закрытых глаз для нарушения
seatbelt_check_interval=30.0 # Интервал проверки ремня
phone_threshold=4.0         # Время использования телефона
cigarette_threshold=3.0     # Время курения
violation_cooldown=60.0     # Кулдаун нарушений
```

#### 🛠️ Установка и запуск
1. Установка зависимостей
```
pip install -r requirements.txt
```
2. Запуск с веб-камеры
```
python main.py --input 0 --save-dir webcam_violations
```
3. Запуск с видеофайла
```
python main.py --input video.mp4 --save-dir video_violations
```

4. Программный запуск
```python
import sys
import os

os.environ['CUDA_VISIBLE_DEVICES'] = '0'
sys.path.insert(0, os.path.dirname(os.path.dirname(__file__)))

from main import process_webcam

if __name__ == "__main__":
    process_webcam(
        camera_id=0,
        save_dir='webcam_violations',
        show_preview=True,
        enabled_detectors=['all'],  # Все детекторы
        disabled_detectors=[]       # Ничего не отключено
    )
```
5. Селективный запуск детекторов
```python 
# Только DMS и движение
process_webcam(
    camera_id=0,
    enabled_detectors=['dms', 'movement'],
    disabled_detectors=['forbidden', 'cv', 'yolo', 'dark']
)
# Все кроме DMS
process_webcam(
    camera_id=0,
    enabled_detectors=['all'],
    disabled_detectors=['dms']
)
```

#### ⚙️ Конфигурация детекторов
Доступные детекторы:

- cv - анализ качества изображения

- dark - детекция темных областей

- yolo - детекция объектов

- movement - детекция движения камеры

- forbidden - детекция запрещенных предметов

- dms - система мониторинга водителя

### **Параметры командной строки:**
```
--input                  # Источник видео (0 для веб-камеры, путь к файлу)
--save-dir               # Директория для сохранения нарушений
--show-preview           # Показывать превью (True/False)
--enabled-detectors      # Список включенных детекторов
--disabled-detectors     # Список отключенных детекторов
--max-duration           # Максимальное время обработки (секунды)
```

### 🔧 Решение проблем
1. Проблемы с веб-камерой
```
# В webcam_processor.py изменить:
self.cap = cv2.VideoCapture(self.camera_id, cv2.CAP_DSHOW)
```
2. Проблемы с загрузкой моделей

Убедитесь, что файлы моделей находятся в правильных директориях:

**src/utils/models/yolov8n.pt**

**src/utils/models/dms_model.pt**

*Система автоматически скачает недостающие модели*

3. Низкая производительность
```
# Отключить ненужные детекторы:
enabled_detectors=['movement', 'dms']

# Увеличить кулдауны:
violation_cooldown=60.0
```
4. Ложные срабатывания

- Настройте пороги детекторов под ваше окружение

- Используйте фильтрацию по времени (min_movement_duration, min_detection_duration)

- Настройте кулдауны для предотвращения спама

### 📈 Статистика и мониторинг
